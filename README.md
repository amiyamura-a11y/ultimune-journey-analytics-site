# ULTIMUNE | Journey Analytics（静的HTML版）

資生堂アルティミューン カスタマージャーニー／Golden Path 分析ダッシュボードの単一HTML版です。`index.html` に正規化済みの個票を埋め込み、すべての集計をブラウザ内で再計算します。

- 公開URL: https://amiyamura-a11y.github.io/ultimune-journey-analytics-site/
- 生成元: https://github.com/amiyamura-a11y/shiseido_customerjourney_utm （`backend/scripts/export_static_html.py`）
- 更新方法: 生成元で再生成した HTML を `index.html` として上書きし push する
